# SpaceX Clone

A simple SpaceX-inspired landing page built with HTML5 and CSS3. The page uses a dark theme and presents a Starship hero section, a space image, vehicle information cards, and a recent mission section.

## Features

- Dark SpaceX-inspired layout
- Header with navigation links for Missions, Rockets, Starlink, and About
- Starship hero section with a call-to-action button
- Space image section
- Vehicle cards for Falcon 9, Falcon Heavy, and Starship
- Recent mission section
- Hover effects on links, buttons, and vehicle cards

## Built With

- HTML5
- CSS3

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Nila-7/spacex-clone.git
   ```

2. Open the downloaded folder.
3. Open `spaceX.html` in your web browser.

No extra packages or build tools are required.

## Project Structure

```
spacex-clone/
└── spaceX.html
```

## Notes

- This is a front-end practice project for learning HTML and CSS.
- The hero image is loaded from Unsplash, so an internet connection is needed to display it.
- Navigation links and buttons are currently presentation-only; no backend or real navigation functionality has been added.
